myFlix Movie API

The myFlix API is a backend service built with Node.js, Express, and MongoDB. It serves as the server-side component for the myFlix web application, providing users with secure access to movie data, user management features, and authentication.

See on Github

Project Scope

Movie Data Access
  • Retrieve a list of all movies
  • Get detailed information about a single movie (title, description, genre, director, image)
  • Access data about specific genres and directors
User Management
  • User registration and profile updates (username, password, email, birthday)
  • Add or remove movies from a user’s list of favorites
  • Secure authentication and authorization with JWT and Passport.js
  • Deregister an account if desired
Backend Design
  • REST architecture with clear, tested endpoints
  • MongoDB database modeled with Mongoose
  • Middleware for logging, validation, and data security
  • Cross-Origin Resource Sharing (CORS) for client-side integration
Deployment
  • Hosted database on MongoDB Atlas
  • API deployed on Heroku for public access

Technology Used

  • Node.js & Express: Server framework and request handling
  • MongoDB & Mongoose: Database and schema modeling
  • JWT & Passport.js: Authentication and authorization
  • CORS: Enabling cross-origin requests
  • Heroku: API deployment
  • MongoDB Atlas: Cloud database hosting

Reflections on the Project

Building the myFlix API was my first deep dive into backend development. I learned how to structure a server-side application, design RESTful endpoints, and connect them to a cloud-based database. Implementing authentication and authorization was especially challenging but rewarding, as it gave me insight into how security is managed in real-world applications. This project strengthened my understanding of the MERN stack and gave me confidence in full-stack development.
