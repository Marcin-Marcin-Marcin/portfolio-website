myFlix React Client

The myFlix client is a single-page movie application built with React. It connects to the myFlix REST API and provides movie enthusiasts with an intuitive interface to explore films, view details, and manage their personal favorites list.

Client Repo Backend Repo Live Website

Project Scope

Movie Browsing & Search
  • Display all movies with images, titles, and descriptions
  • Search and filter movies by title
  • Navigate seamlessly through multiple views using React Router
Movie Details
  • View information about a single movie, including genre and director
  • Add or remove a movie from the favorites list
User Accounts
  • Register as a new user (username, password, email, birthday)
  • Log in securely and maintain session state
  • Update personal profile details
  • Deregister if desired
  • Display and manage a list of favorite movies
UI/UX
  • Clean, responsive design using Bootstrap and custom SASS styling
  • State management with Redux for efficient updates
  • Optimized bundling and build process with Parcel
  • Fully deployed and accessible through Netlify

Technology Used

  • Client: React (ES2015+), React Router, Redux, Bootstrap 5 & SASS, Parcel, Netlify
  • Backend: myFlix REST API (Node.js, Express, MongoDB, JWT, Passport.js, CORS, MongoDB Atlas, Heroku)

Reflections on the Project

Developing the myFlix client was my first major experience with React, which was both exciting and challenging. I learned how to build reusable components, manage state effectively, and create a responsive user experience. Integrating the client with the API gave me valuable full-stack experience, while problem-solving issues (such as outdated materials and changing dependencies) helped me grow as an independent developer. This project gave me a clear picture of how modern web applications are structured in a professional environment.
