Meet App

The Meet App is a progressive web application (PWA) designed to help users discover upcoming events in different cities. Built with React and powered by serverless functions, it provides a fast, reliable, and cross-platform experience that works seamlessly online and offline.

See on Github See Live Project

Project Scope

Event Discovery & Browsing
  • Search for events by city with auto-suggestions
  • Specify how many events to display
  • Expand or collapse event details
Progressive Web App (PWA) Features
  • Offline functionality using service workers and cached data
  • Install the app as a shortcut on desktop or mobile home screens
  • Responsive design across all devices
Data Visualization
  • Interactive scatterplots showing the number of events by city
  • Pie charts visualizing event categories and trends
Backend & Testing
  • Serverless backend powered by AWS Lambda functions
  • Secure authentication using OAuth2 with Google Calendar API
  • Test-Driven Development approach with Jest, Cucumber, and Puppeteer
  • Continuous deployment and performance monitoring

Technology Used

  • React: Frontend development
  • AWS Lambda: Serverless backend functions
  • Google Calendar API & OAuth2: Event data and secure authentication
  • Jest & Cucumber: Unit, integration, and end-to-end testing
  • Recharts: Data visualizations
  • Service Workers: Offline functionality and PWA features
  • Vercel: Deployment and hosting

Reflections on the Project

The Meet App deepened my understanding of Progressive Web Apps and serverless architecture. Implementing offline functionality and “add to home screen” features showed me how PWAs bridge the gap between web and native apps. Working with TDD gave me valuable experience in writing tests first and building features around them, which improved both my code quality and confidence as a developer. Data visualization with charts was a highlight, as it allowed me to present insights in a clear and engaging way.
