Pokédex App

The Pokédex App is a responsive JavaScript web application that enables users to discover and explore different Pokémon. The app fetches data from the PokéAPI and displays it in an interactive list, allowing users to view detailed information about each Pokémon.

See on Github See Live Project

Project Scope

  • Dynamic Pokémon List: Pokémon data is fetched from the PokéAPI and displayed in a responsive layout.
  • Detailed View: Users can view individual Pokémon details (name, height, and images) in a Bootstrap-powered modal.
  • Search Functionality: Pokémon can be searched by name for quick access.
  • Responsive Design: Optimized for desktop and mobile, ensuring accessibility and usability.
  • Interactive UI: Smooth navigation and modal interactions for an engaging experience.

Technology Used

  • JavaScript (ES6): Fetch API, asynchronous requests, DOM manipulation
  • HTML5 & CSS3: Structure, layout, and styling
  • Bootstrap 5: Responsive grid system, modal implementation
  • PokéAPI: Source of Pokémon data
  • GitHub Pages: Hosting and deployment

Reflections on the Project

This project was my introduction to working with external APIs and building an application with dynamic content. It gave me hands-on experience with asynchronous JavaScript, modular code organization, and responsive UI design. One of the key takeaways was learning how to fetch and display data efficiently while handling user interactions smoothly.
