myFlix Angular Client

The myFlix Angular Client is a single-page application built with Angular that connects to the myFlix REST API. It enables users to explore a collection of movies, view details about genres and directors, and manage their personal profiles and favorites list.

See on Github See Live Project

Project Scope

User Authentication
  • Registration and login forms with Angular Material
  • Secure access to app features once authenticated
Movie Exploration
  • Browse a catalog of movies displayed as Angular Material cards
  • View detailed information for each movie
  • Access additional views for directors and genres directly from a movie’s details
User Profile Management
  • Update personal information
  • Add or remove movies from the favorites list
  • Deregister an account if desired
UI & Documentation
  • Responsive design using Angular Material components
  • Routing for seamless navigation across views
  • Typedoc comments and JSDoc technical documentation for handoffs

Technology Used

  • Angular (v9+): Framework for building the client-side application
  • Angular Material: UI components and styling
  • TypeDoc & JSDoc: Code comments and technical documentation
  • Node.js & npm: Development environment
  • GitHub Pages: Hosting and deployment

Reflections on the Project

Working on the myFlix Angular Client gave me the opportunity to deepen my skills in a second modern frontend framework beyond React. Using Angular Material streamlined the UI design process and taught me how to work with pre-built, accessible components. This project also highlighted the importance of documentation - producing Typedoc and JSDoc comments improved my ability to communicate technical details clearly and create reliable handoffs for other developers.
