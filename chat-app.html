Chat App

Chat App is a mobile chat application built with React Native and Expo. It provides users with a real-time, cross-platform messaging experience, supporting text, image sharing, and location sharing. The app also offers offline access to conversations by storing messages locally.

See on Github

Project Scope

User Onboarding
  • Anonymous login via Firebase Authentication
  • Start screen allowing users to enter a name and choose a background color for the chat interface
Chat Features
  • Real-time messaging powered by Firebase Firestore
  • Sending and receiving text messages
  • Sharing images from the device’s library or camera
  • Sending live location data displayed on a map view
Offline Support
  • Messages stored locally with AsyncStorage
  • Conversations accessible when offline
  • Images and data synced once the user reconnects
UI & Accessibility
  • Chat interface implemented with the Gifted Chat library
  • Designed with accessibility in mind, including screen reader compatibility
  • Responsive and styled according to provided design specifications

Technology Used

  • React Native: Cross-platform mobile development
  • Expo: Development platform for native apps
  • Firebase Firestore: Cloud database for storing conversations
  • Firebase Authentication: Anonymous login and user management
  • Firebase Cloud Storage: Storage for images
  • Gifted Chat: Pre-built UI components for chat functionality
  • AsyncStorage: Local offline message storage

Reflections on the Project

Building Chat App was my first experience creating a fully functional mobile application. I quickly adapted to React Native, as its similarities with React made the learning curve smooth. Debugging was one of the biggest challenges, since some errors only appeared when simulating on Android Studio rather than in the browser. This project taught me the importance of testing directly in native environments and strengthened my skills in managing both online and offline data in real-time applications.
